# Exchange Dashboard

React + TypeScript SPA по тестовому заданию. Макет воспроизведён по предоставленным скриншотам: Inter, светлый фон, белые панели, тёмные кнопки, адаптивная боковая навигация.

## Запуск

Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Приложение: http://127.0.0.1:5173. Mock API: http://127.0.0.1:3001.

Вход: `demo@example.com` / `demo123`.

```sh
npm run build
npm test
node mock/smoke.mjs
```

Последняя команда требует работающий mock API. `npm run preview` запускает только статическую сборку: для входа в этом режиме нужен отдельно запущенный mock API и `VITE_AUTH_API`, заданный при сборке. На Vercel вместо json-server работают Functions из `api/`; см. DEPLOY.md. В dev Vite проксирует `/api` на json-server.

## Структура

- `src/app`: общий layout и навигация.
- `src/pages`: login, rates, cards, загрузка страниц через React.lazy.
- `src/features/auth`: контекст сессии, вход/выход, проверка `/me`, защита маршрутов.
- `src/features/rates`: типы и запросы валютного API, кэширование и отмена через TanStack Query.
- `src/features/cards`: Zod-схема формы и тесты.
- `src/shared`: HTTP helper и локальные компоненты shadcn/ui (Button с Radix Slot/CVA, Input, Textarea), стилизованные по макету.
- `mock`: json-server 0.17 с отдельными auth endpoints и файловой базой.

## API и поведение

Курсы и история: [Frankfurter v2](https://frankfurter.dev/), публичный API без ключа. `/v2/rates?base=USD&quotes=...` для таблицы, `from` / `to` для графика. Периоды 1W, 1M, 3M, 6M, 1Y отсчитываются от даты последнего опубликованного курса. Значения означают количество выбранной валюты за 1 USD, как числа на скриншоте. Данные обновляются ежедневно; выходные могут отсутствовать. Loading, ошибки и повторная загрузка предусмотрены отдельно для таблицы и графика.

Buy и Surrender рассчитаны как справочный курс ±2%, что подписано под таблицей. Это демонстрационные значения, поскольку API не предоставляет банковские котировки. Change и Time в таблице отмечены прочерками: API не отдаёт внутридневное время и изменение. Процент на графике рассчитан из первого и последнего значений выбранного периода. Валюты: AUD, CAD, CHF, EUR, GBP, JPY.

Авторизация: POST `/login`, GET `/me`, POST `/logout`. Токен сохраняется локально, валидируется сервером при перезагрузке; logout удаляет mock-сессию. Прямое чтение users/sessions закрыто. Пароль в seed хранится открыто исключительно для локального тестового mock. Для сброса остановите API, удалите `mock/db.json` и запустите заново.

Форма на react-hook-form и Zod: обязательны title, description, priority. Дополнительно status, assignee, deadline, теги (Enter/запятая, удаление кликом), изображения (выбор/drag-and-drop, удаление, PNG/JPEG/WebP до 5 MB, максимум 5). Preview показывает текущие валидные данные; Back/Edit возвращают их в форму. Create Card показывает alert с введёнными данными в JSON (включая метаданные изображений), имитируя запрос на бэкенд, затем открывает превью. Файлы в JSON представлены метаданными, реальной отправки на сервер нет. Cancel очищает форму. Черновик живёт в памяти страницы.

## Статус сдачи

Проверено: TypeScript + production build, 3 unit-теста схемы, 7 HTTP-проверок mock-авторизации, HTTP 200 dev-сервера, реальные ответы Frankfurter для текущих курсов и истории. npm audit после обновления Vitest: 0 уязвимостей. Проверка интерфейса в браузере не завершена: инструмент превью вернул timeout. Адаптивная CSS-вёрстка реализована, но визуальная проверка на desktop/tablet/mobile остаётся.

Проект подготовлен для Vercel: frontend и mock Functions размещаются вместе. Локально по-прежнему используется json-server. Настройка AUTH_SECRET, Root Directory и проверки публикации описаны в [DEPLOY.md](./DEPLOY.md). Production: https://exchange-dashboard-react-ts.vercel.app. Деплой выполнен через Vercel CLI; автодеплой из GitHub пока не подключён.

## Правки интерфейса

Иконки навигации взяты из предоставленных SVG. Календарь react-day-picker использует en-US, включая названия месяцев и дней недели; выбранная дата отображается по-английски, внутри формы хранится YYYY-MM-DD. Календарный popover использует Radix (фокус, Escape, возврат фокуса). Состояния ожидания отображаются скелетонами с доступными подписями; анимация отключается при prefers-reduced-motion.
